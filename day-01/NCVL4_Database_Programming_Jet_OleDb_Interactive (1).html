3. Display and search records

Display all records in a DataGridView

Private Sub LoadStudents()
    Using con As New OleDbConnection(conString)
        Dim sql As String =
            "SELECT StudentID, FullName, Course, [Mark] " &
            "FROM Students ORDER BY StudentID"
        Using da As New OleDbDataAdapter(sql, con)
            Dim dt As New DataTable()
            da.Fill(dt)
            DataGridView1.DataSource = dt
        End Using
    End Using
End Sub

SELECT reads records. DataTable holds the results in memory. DataGridView shows the rows.

Search safely using a parameter

Dim sql As String =
    "SELECT * FROM Students WHERE StudentID = ?"
Using con As New OleDbConnection(conString)
    Using cmd As New OleDbCommand(sql, con)
        cmd.Parameters.Add("@id", OleDbType.Integer).Value =
            Integer.Parse(txtID.Text)
        Using da As New OleDbDataAdapter(cmd)
            Dim dt As New DataTable()
            da.Fill(dt)
            DataGridView1.DataSource = dt
        End Using
    End Using
End Using
In Jet OleDb SQL, ? is a placeholder. Parameter order matters. The first parameter matches the first ?.

4. Save a new student (INSERT)

Save button code

Private Sub btnSave_Click(sender As Object,
    e As EventArgs) Handles btnSave.Click
    Dim score As Integer
    If txtName.Text.Trim() = "" OrElse
       txtCourse.Text.Trim() = "" OrElse
       Not Integer.TryParse(txtMark.Text, score) OrElse
       score < 0 OrElse score > 100 Then
        MessageBox.Show("Enter valid student details.")
        Return
    End If

    Dim sql = "INSERT INTO Students " &
        "(FullName, Course, [Mark]) VALUES (?, ?, ?)"
    Try
        Using con As New OleDbConnection(conString)
            Using cmd As New OleDbCommand(sql, con)
                cmd.Parameters.Add("@name", OleDbType.VarWChar).Value = txtName.Text.Trim()
                cmd.Parameters.Add("@course", OleDbType.VarWChar).Value = txtCourse.Text.Trim()
                cmd.Parameters.Add("@mark", OleDbType.Integer).Value = score
                con.Open()
                cmd.ExecuteNonQuery()
            End Using
        End Using
        LoadStudents()
        MessageBox.Show("Student saved!")
    Catch ex As Exception
        MessageBox.Show(ex.Message)
    End Try
End Sub

ExecuteNonQuery() runs INSERT, UPDATE, or DELETE. It returns the number of rows affected.

5. Change and delete records

UPDATE changes an existing row

Dim sql = "UPDATE Students SET Course = ?, " &
          "[Mark] = ? WHERE StudentID = ?"
Using con As New OleDbConnection(conString)
    Using cmd As New OleDbCommand(sql, con)
        cmd.Parameters.Add("@course", OleDbType.VarWChar).Value = txtCourse.Text
        cmd.Parameters.Add("@mark", OleDbType.Integer).Value = score
        cmd.Parameters.Add("@id", OleDbType.Integer).Value = studentID
        con.Open()
        Dim changed As Integer = cmd.ExecuteNonQuery()
    End Using
End Using

DELETE removes a row

Dim sql = "DELETE FROM Students WHERE StudentID = ?"
Using con As New OleDbConnection(conString)
    Using cmd As New OleDbCommand(sql, con)
        cmd.Parameters.Add("@id", OleDbType.Integer).Value = studentID
        con.Open()
        Dim deleted As Integer = cmd.ExecuteNonQuery()
    End Using
End Using
Never forget WHERE! Without it, an UPDATE can change every record and DELETE can remove every record. Confirm before deleting.

6. BindingSource and navigation

Why use a BindingSource?

A DataGridView displays many rows. A BindingSource helps us manage the current record and move from one record to another. We can show the current student's details in TextBoxes or Labels.

Think of a BindingSource as a bookmark in a class register. You can go to the next student or the previous one without searching the whole register yourself.
Private bs As New BindingSource()

Private Sub LoadStudents()
    Using con As New OleDbConnection(conString)
        Dim da As New OleDbDataAdapter(
            "SELECT * FROM Students ORDER BY StudentID", con)
        Dim dt As New DataTable()
        da.Fill(dt)
        bs.DataSource = dt
        DataGridView1.DataSource = bs
        txtName.DataBindings.Clear()
        txtName.DataBindings.Add("Text", bs, "FullName")
    End Using
End Sub

Private Sub btnNext_Click(sender As Object,
    e As EventArgs) Handles btnNext.Click
    bs.MoveNext()
End Sub

Private Sub btnPrevious_Click(sender As Object,
    e As EventArgs) Handles btnPrevious.Click
    bs.MovePrevious()
End Sub
BindingSource moves through records in memory. It does not automatically save edits to Access. You still need the correct database update code.
